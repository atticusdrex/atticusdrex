## 🎓 About Me

I'm a **PhD student at the Georgia Institute of Technology**, researching **multifidelity methods for surrogate modeling and uncertainty quantification**. My work focuses on making high-fidelity simulation cheap — combining models of varying cost and accuracy to learn more from less data.

- 🔬 **Research Focus:** Multifidelity Surrogate Modeling · Uncertainty Quantification · Gaussian Processes
- 🧠 **Toolkit:** JAX · Bayesian Inference · Monte Carlo Estimation · Scientific ML
- 🌐 **Learn more:** [atticusdrex.github.io](https://atticusdrex.github.io/website/)

## 🧪 Featured Project — Elyza

<div align="center">
<img src="https://img.shields.io/badge/JAX-0868AC?style=flat-square&logo=jax&logoColor=7BCCC4"/>
<img src="https://img.shields.io/badge/Pydantic-7BCCC4?style=flat-square&logo=pydantic&logoColor=084081"/>
<img src="https://img.shields.io/badge/Python-0868AC?style=flat-square&logo=python&logoColor=7BCCC4"/>
<img src="https://img.shields.io/badge/Gaussian%20Processes-7BCCC4?style=flat-square&logoColor=084081"/>
<img src="https://img.shields.io/badge/Monte%20Carlo-0868AC?style=flat-square&logoColor=7BCCC4"/>
</div>

> **elyza** is a JAX-backed library for multifidelity surrogate modeling, inference, and uncertainty quantification.

It provides a set of composable, Pydantic-validated building blocks for:

- 🧩 Defining simulation inputs and evaluators
- 📈 Fitting Gaussian process surrogates, including multifidelity/autoregressive models
- 💰 Combining models of varying cost and accuracy with multifidelity Monte Carlo estimators
